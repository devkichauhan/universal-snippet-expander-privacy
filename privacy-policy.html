Universal Snippet Expander

Privacy Policy

Last updated: May 4, 2026

Universal Snippet Expander stores user-created shortcuts locally in the browser using Chrome extension storage.

What the extension stores

  • Shortcut names
  • Shortcut trigger text such as ;intro
  • Shortcut message content

What the extension does not do

  • It does not send your snippets to our servers
  • It does not sell personal data
  • It does not track browsing history
  • It does not collect payment information in this version

Where data is stored

  • Data is stored in chrome.storage.local on the user's browser profile

Site access

The extension runs only on supported sites where snippet expansion is needed:

  • Gmail
  • Outlook Web
  • LinkedIn
  • Yahoo Mail

The extension reads the active editor content only to detect a matching shortcut and replace it with the saved snippet text.

Data removal

Users can remove their saved shortcuts at any time from the extension popup or by uninstalling the extension.
